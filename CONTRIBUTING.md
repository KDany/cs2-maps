# Contributing

Thanks for wanting to improve these maps! A few simple rules:

## Variants vs. contributions

- **Community variants** (Wingman cuts, themed versions, etc.) belong in **your own fork**. Open an issue with a link and I will list it in the README.
- **Pull requests** to this repository are for fixes and improvements to the original maps (bugs, clipping, optimization, missing assets, etc.).

## Licensing of contributions

By submitting a pull request, you agree that:

1. your contribution is your own work (or you have the right to submit it), and
2. it is licensed under **CC BY-NC-SA 4.0**, like the rest of this repository, **and** you additionally grant KDany a non-exclusive, perpetual, worldwide, royalty-free right to use, modify and relicense your contribution as part of the original maps — including for possible official/commercial releases (for example, if a map gets selected by Valve).

This keeps the original maps in one hand, so a future official release does not require tracking down every contributor. If you do not agree with point 2, please keep your changes in your fork instead.

## Assets

- Only submit assets you made yourself or that are licensed compatibly with CC BY-NC-SA 4.0. State the source and license of any third-party asset in your pull request.
- Do not commit compiled files (`game/`, `.vpk`, `_c` files) — only `content/` source files.
- Install [Git LFS](https://git-lfs.com/) (`git lfs install`) before committing textures, models or audio.
