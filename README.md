# KDany's CS2 map source files

Welcome to my central repository for Counter-Strike 2 mapping projects. This repository serves as a personal portfolio and a public archive containing the raw source files, geometry, and custom assets for my custom maps built using the Source 2 Hammer Editor.

Feel free to explore the files, learn from the geometry setup, or use the source files to create your own community variants of my maps — just like in the good old 1.6 days!

## 📂 Repository Structure

This repository only stores the raw, uncompiled development source files of each map (the content of the map's addon folder under the engine's `content/csgo_addons/` directory). Compiled game files (the `game/` directory with `.vpk` / `_c` files) and temporary compiler output are excluded via `.gitignore`.

Each map has its own folder in the root of the repository, named after the map (the name already contains the game mode prefix, e.g. `de_` for Defusal). The folder matches the CS2 addon folder layout:

```
<map_name>/
├── maps/        -> the primary .vmap file(s)
├── materials/   -> custom materials and textures (if any)
├── models/      -> custom models (if any)
├── panorama/    -> radar / overview images (if any)
└── sounds/      -> custom sounds (if any)
```

> **Downloading:** All map files are stored as regular Git files, so a simple `git clone` or GitHub's **Code > Download ZIP** gives you everything you need — no extra tools required.
>
> **Tip:** If you only need one map, you can use a [sparse checkout](https://git-scm.com/docs/git-sparse-checkout) to download just that map's folder:
> ```
> git clone --filter=blob:none --sparse https://github.com/KDany/cs2-maps
> cd cs2-maps
> git sparse-checkout set de_dust2_long
> ```

## 🛠️ How to Open a Map in Hammer

1. Open the **CS2 Workshop Tools** and create a new addon. Give it **the same name** as the map's folder in this repository (e.g. `de_mymap`).
2. Close the tools, then copy the **entire contents** of `<map_name>/` from this repository (e.g. `de_mymap/`) into your own
   `.../steamapps/common/Counter-Strike Global Offensive/content/csgo_addons/<map_name>/` folder (merge/overwrite when asked).
3. Launch the Workshop Tools with your addon, open Hammer, choose **File > Open**, and select the `.vmap` file from the `maps/` folder.

Copying the whole folder (not just the `.vmap`) makes sure that every custom material, model and sound the map depends on is in place.

## 🏷️ Versions

Every map has a **release** Workshop item and a separate **playtest** Workshop item for testing upcoming versions. Each upload gets a version number, and the matching source state is tagged in this repository:

| Map | Release | In playtest | Changes |
| :--- | :--- | :--- | :--- |
| **de_dust2_long** | v1.0 · [Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3730804227) · *not tagged (released before this repository)* | v1.1-beta.3 · [Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3730701113) | [CHANGELOG](./CHANGELOG.md#de_dust2_long) |

- Release tags are named `<map_name>-v<version>` (e.g. `de_dust2_long-v1.1`), playtest tags `<map_name>_dev-v<version>-beta.<n>` (e.g. `de_dust2_long_dev-v1.1-beta.2`). Browse them under [Tags](https://github.com/KDany/cs2-maps/tags), or download a release's compiled `.vpk` from [Releases](https://github.com/KDany/cs2-maps/releases).
- The playtest version uses the map name `<map_name>_dev` (e.g. `de_dust2_long_dev`), so it can be installed next to the release version.
- To create or update the local `_dev` addon from this repository (and back), use [`tools/sync-dev-addon.ps1`](./tools/sync-dev-addon.ps1):
  ```
  powershell -ExecutionPolicy Bypass -File .\tools\sync-dev-addon.ps1 -Map de_dust2_long          # repo -> <map>_dev addon
  powershell -ExecutionPolicy Bypass -File .\tools\sync-dev-addon.ps1 -Map de_dust2_long -ToRepo  # <map>_dev addon -> repo
  ```
- The full history of every map is in [CHANGELOG.md](./CHANGELOG.md).
